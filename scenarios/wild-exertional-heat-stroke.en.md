## Learning objectives

**Technical skills**

- Recognises exertional heat stroke: core temperature >40°C + CNS dysfunction.
- ★ Uses a core (rectal) thermometer; knows oral/tympanic/axillary readings are misleading.
- ★ Applies 'cool first, transport second' — cold-water immersion without delay.
- Monitors cooling rate (~0.2°C/min) and stops active cooling at ~38.6–39°C.
- Screens for and manages rhabdomyolysis/AKI/coagulopathy; avoids antipyretics.

**Non-technical skills**

- Prioritises: starts cooling before full work-up/transport.
- Closed-loop communication and task sharing (immersion set-up).
- Improvises a cooling set-up with limited field resources.
- Justifies admission/discharge decisions.
- Communicates with patient/companions and manages safety (seizure/aspiration).

## Instructor summary

A 24-year-old man collapsed with confusion and ataxia during a trail race on a hot summer day; race officials bring him to the ED. Skin hot, flushed and sweaty; agitated and confused. This is exertional heat stroke (core 41.5°C). Delayed cooling leads to seizures and deterioration.

**Scenario progression:** Early core temperature measurement + immediate aggressive cooling (ideally cold-water immersion) leads to recovery. Delayed cooling / wrong thermometer → seizures, worsening encephalopathy. Failure to stop cooling at ~38.6–39°C → overcooling/shivering. The case ends with rhabdomyolysis/AKI management and ICU admission.

## Preparation

- **Supporting documents / results:** Field handover note; CK 12,000 U/L, creatinine 1.8 mg/dL, K⁺ 5.6, raised AST/ALT, INR 1.6, low platelets, urine myoglobin (+); ECG sinus tachycardia; metabolic acidosis on blood gas.
- **Roles:** Technician; instructor; facilitator 1: nurse; facilitator 2: race official/friend (gives history).
- **Costume / moulage:** Patient: running kit, sweaty, flushed; confused.
- **Pre/post reading:** WMS Heat Illness 2024 summary; cold-water immersion protocol card; rhabdomyolysis management card.
- **Environment:** Two phases: (1) field — hot summer setting; (2) ED. Tub/tarp + ice + water for cooling.
- **Actor / facilitator notes:** Official: 'At kilometre 15 he started staggering, talking nonsense, then collapsed; it was very hot.' Nurse: if the team delays cooling for imaging/transport asks 'shall we start cooling first?'; reports shivering if cooling continues below 38.5°C.
- **Equipment:** Core (rectal) thermometer, immersion tub/tarp + ice + water, fan, wet sheets, ice packs, monitor, IV set, airway/seizure kit, urinary catheter, blankets.
- **Medications:** 0.9% NaCl; benzodiazepine (midazolam/diazepam); antiemetic. Antipyretics (paracetamol/NSAIDs) are ineffective — do not use; dantrolene not recommended.

## Learner briefing

> A hot summer day; a young runner who collapsed during a trail race is brought to the ED. Equipment is complete; a cooling set-up is available. Roles are assigned. This is a safe learning environment.

## Initial state

Agitated and confused (GCS 13; E3 V4 M6), hot flushed sweaty skin.

**Vital signs:** HR (/min): 140 · BP (mmHg): 95/55 · RR (/min): 28 · SpO₂ (%): 96 · Core temp (°C): 41.5 · Glucose (mg/dL): 110 · GCS: 13

## Scenario flow

### State 1 — Handover / diagnosis (Time: 0-3 min)

**Expected actions (★ critical)**

- ABC; monitoring, large-bore IV, oxygen.
- ★ Core (rectal) temperature.
- Diagnosis: hyperthermia + altered mental status = exertional heat stroke.
- Assign team members to set up cooling.
- Brief history: exertion, heat, collapse.

**Patient response / triggers:** Rectal 41.5°C. Oral/tympanic readings are misleadingly low (~38–39°C) → facilitator asks 'did we measure core temperature?'.

**Vital signs:** HR (/min): 140 · BP (mmHg): 95/55 · RR (/min): 28 · Core temp (°C): 41.5

### State 2 — Aggressive cooling (Time: 3-8 min)

**Expected actions (★ critical)**

- ★ Immediate cold-water immersion (head above water) — 'cool first'.
- If immersion unavailable: wet sheets + fan + ice packs (neck/axillae/groin).
- Continuous core temperature monitoring; do not delay cooling for transport/tests.
- IV 0.9% NaCl; airway and seizure safety.

**Patient response / triggers:** Correct cooling → core falls ~0.2°C/min (41.5→~40°C). If cooling is delayed → core stays high → state 3 (seizure).

**Vital signs:** Core temp (°C): 40.0

**Transitions:** cooling delayed → State 3

### State 3 — Complications and maintenance (Time: 8-14 min)

**Expected actions (★ critical)**

- If seizure: ★ benzodiazepine; protect the airway.
- Continue cooling.
- Interpret labs: very high CK (rhabdomyolysis), raised creatinine, raised INR / low platelets.
- ★ No antipyretics; no dantrolene.
- Fluids for rhabdomyolysis; monitor urine output.

**Patient response / triggers:** With cooling, core 40→39°C; seizure stops with benzodiazepine. Antipyretics do not lower temperature. Haemodynamics improve with fluids + cooling.

**Vital signs:** HR (/min): 120 · BP (mmHg): 105/65 · Core temp (°C): 39.0

### State 4 — Stop cooling and admit (positive ending) (Time: 14-18 min)

**Expected actions (★ critical)**

- ★ Stop active cooling when core reaches ~38.6–39°C.
- Reassess; continue rhabdomyolysis/AKI/coagulopathy management.
- Disposition: organ involvement → ICU.
- Update companions.

**Patient response / triggers:** Core 38.8°C; GCS returns to 15. Stable, admitted to ICU — END OF SCENARIO.

**Vital signs:** Core temp (°C): 38.8 · GCS: 15

### State 5 — Alternative: overcooling / wrong thermometer (Time: any)

**Expected actions (★ critical)**

- If cooling continues below 38°C → ★ stop cooling, rewarm if needed.
- If cooling is delayed because tympanic/oral reading shows 'no fever', facilitator requests core measurement.
- The team corrects course and returns to state 4.

**Patient response / triggers:** Overcooling → shivering, core below 37°C (teaching point). If corrected, ends positively via state 4.

**Vital signs:** Core temp (°C): <37

**Transitions:** decision corrected → State 4

## Debriefing

**Key learning points**

- Exertional vs classic heat stroke; the rationale for 'cool first, transport second'.
- Why a core (rectal) thermometer? Peripheral readings mislead.
- Cooling methods and rates; superiority of cold-water immersion.
- Why stop active cooling at ~38.6–39°C.
- Why antipyretics are ineffective; no role for dantrolene.
- Screening for rhabdomyolysis/AKI/coagulopathy and disposition.

**Common errors**

- Delaying cooling for tests/transport.
- Underestimating temperature with oral/tympanic readings.
- Trying to lower temperature with antipyretics.
- Not stopping active cooling, causing overcooling.
- Missing rhabdomyolysis/AKI.
- Neglecting seizure/aspiration safety.
